# TachiReel

TachiReel is a gentle photo and short-video social app built with Expo SDK 58,
React Native 0.88, Expo Router and Supabase. **Reelyx** is the immersive
short-video feed.

## Stack

- Expo Router routes in `src/app/`
- Shared UI in `src/components/`
- Warm Editorial theme in `src/theme/`
- Supabase helpers in `src/lib/`, with an in-memory Preview mode when no
  backend is configured
- Server-side support assistant in `supabase/functions/tachireel-support-chat/`

## Commands

```bash
npm start          # Expo dev server
npm run web        # browser
npm run ios        # iOS simulator
npm run android    # Android emulator
npm run lint         # expo lint
npm run typecheck    # tsc --noEmit
npm run verify:rbac  # local PostgreSQL RBAC assertions
npm run seed:super-admin  # server-side admin@admin.com bootstrap
npx expo export --platform web
```

Use `npx expo install <package>` to add dependencies.

## Local configuration

Copy `.env.example` to `.env` and set:

- `EXPO_PUBLIC_SUPABASE_URL`
- `EXPO_PUBLIC_SUPABASE_ANON_KEY`
- `EXPO_PUBLIC_APP_URL` for share and guardian links

Without Supabase, TachiReel runs in Preview mode. Demo login is
`admin@admin.com` / `password`; the session is in memory and resets on reload.

## Supabase

See `docs/SUPABASE.md` for the full setup guide: environment variables,
migration order, auth redirects, storage policies, generated types, Edge
Function secrets and the secure Super Admin bootstrap.

`supabase/schema.sql` is the full database schema. It is a fresh-setup script;
only the “Redesign additions” appendix is safe to re-apply to an existing
project. Apply `supabase/admin_schema.sql` and then
`supabase/admin_rbac_v2.sql` after it.

For the support assistant, apply the schema, set the server-only secrets, and
deploy the function:

```bash
supabase secrets set SUPPORT_AI_API_KEY=your-server-side-key
supabase secrets set SUPPORT_AI_MODEL=gpt-4o-mini
supabase functions deploy tachireel-support-chat
```

See `supabase/functions/tachireel-support-chat/README.md` for details. When the
assistant is not configured, the app shows setup guidance and falls back to
help articles and FAQs; it never simulates AI replies.

## Notes

- New posts start in moderation review and only appear in feeds once marked
  safe.
- `post-media` and `avatars` are private buckets; media is served with signed
  URLs.
- Native folders are generated by Expo and should not be edited directly.
- There is no JavaScript unit-test runner configured. `npm run verify:rbac`
  runs local database/authorization integration assertions against a throwaway
  PostgreSQL cluster; it never touches a live Supabase project.
